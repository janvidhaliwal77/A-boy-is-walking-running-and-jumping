Walking, Running and Jumping Boy Animation
Project Report – Animation Subject
Introduction
This project is based on a boy character performing three basic movements: walking, running, and jumping. The project demonstrates the basic principles of 2D/3D character animation.

Project Objectives
To understand the fundamentals of animation.
To create a walking animation.
To create a running animation.
To create a jumping animation.
To understand character movement, timing, and keyframes.
Project Features
1. Walking Animation

Natural walking movement.
Hand and leg coordination.
Smooth body movement.
2. Running Animation

Fast body movement.
Proper arm and leg coordination.
Running cycle animation.
3. Jumping Animation

Take-off movement.
Character jumping in the air.
Smooth landing movement.

Conclusion
This project helped me understand the basic concepts of character animation, including walking, running, and jumping. It improved my knowledge of animation techniques and character movements.
